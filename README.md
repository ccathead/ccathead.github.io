# Catie’s Library

中文优先的双语个人技术博客，内容包括公开研究项目、技术项目、学习笔记与生活记录。

## 本地预览

```bash
pnpm install
pnpm server
```

访问 `http://localhost:4000`。

## Obsidian 写作

- 可发布内容放在 `source/`。
- 草稿可放在 `source/_drafts/`，私人材料放在 `private/`。
- 使用 `templates/` 中的中英文模板。
- 只有完成引用、图片、链接与隐私检查的内容才能设置为 `published: true`。
- 中英文版本使用相同的 `translation_key`。

微信公众号入口将在账号信息和二维码补充后启用。
